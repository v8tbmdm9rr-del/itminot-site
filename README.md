# ITMINOT — сайт неаполитанской пиццерии

Премиальный сайт пиццерии ITMINOT: меню с корзиной, оформление заказа и бронирование столика через WhatsApp, доставка/самовывоз, контакты, и админ-панель для управления меню и бронями.

Стек: Next.js (App Router) · TypeScript · Tailwind CSS v4 · Framer Motion · Zustand · React Hook Form + Zod · Lucide Icons.

## Запуск проекта

```bash
npm install
npm run dev
```

Сайт откроется на [http://localhost:3000](http://localhost:3000).

### Проверка с телефона

`npm run dev` также печатает адрес вида `Network: http://192.168.x.x:3000` — откройте его в браузере телефона, если он подключён к той же Wi-Fi сети (или к точке доступа компьютера). Список разрешённых для этого сетей задан в `next.config.ts` → `allowedDevOrigins` (по умолчанию покрывает частые домашние и мобильные подсети: `192.168.*.*`, `10.*.*.*`, `172.20.10.*` — подсеть Personal Hotspot iPhone). Если ваш адрес не подходит под эти маски, добавьте его точный IP в этот список и перезапустите сервер — иначе Next.js в режиме разработки блокирует запросы с чужого адреса и страница может зависнуть при загрузке.

Продакшн-сборка:

```bash
npm run build
npm run start
```

## Админ-панель

Панель находится по адресу **`/admin`** и защищена паролем.

- Пароль по умолчанию: `itminot-admin-2026`.
- Чтобы задать свой пароль, скопируйте `.env.local.example` в `.env.local` и укажите значение `ADMIN_PASSWORD`, затем перезапустите сервер.

```bash
cp .env.local.example .env.local
```

В панели доступны два раздела:

- **Меню** (`/admin`) — список всех блюд с фильтром по категориям, добавление новых позиций, редактирование названия, категории, описания, состава, веса, цены (в том числе цены для двух размеров у пиццы), отметок (хит/острое/новинка/вег.), удаление позиций. Фото можно загрузить прямо с телефона или компьютера кнопкой «Загрузить фото» — файл автоматически обрежется по ширине, сожмётся и сохранится в `public/images/uploads/`, путь подставится в форму сам (можно и указать путь вручную, если фото уже лежит в `public`).
- **Бронирования** (`/admin/bookings`) — список всех заявок на бронирование столика, отправленных через сайт (имя, телефон, дата, время, количество гостей, пожелания), от новых к старым.

Изменения в меню применяются на сайте сразу — рассылать пересборку не нужно, страницы `/` и `/menu` всегда показывают актуальные данные.

**Важно про безопасность.** Это простая защита паролем для одного администратора, подходящая для небольшого внутреннего инструмента — не полноценная система пользователей с ролями. Обязательно смените пароль по умолчанию перед тем, как выкладывать сайт в открытый доступ.

## Как хранятся данные

- `data/menu.ts` — исходный (посевной) набор блюд. Он используется только один раз, при самом первом запуске, чтобы создать `content/menu.json`.
- `content/menu.json` — рабочий файл меню. Именно его читает сайт и изменяет админ-панель. Файл создаётся автоматически при первом запуске и не входит в архив проекта (в `.gitignore`), так как это изменяемые данные, а не код.
- `content/bookings.json` — все заявки на бронирование, отправленные через сайт. Тоже создаётся автоматически и содержит персональные данные клиентов (имя, телефон) — не публикуйте этот файл.

Если нужно быстро вернуть меню к исходному состоянию — удалите `content/menu.json`, он будет заново создан из `data/menu.ts` при следующем запросе.

Также меню можно редактировать и без панели — напрямую в `content/menu.json` (обычный JSON, каждый пункт соответствует типу `MenuItem` из `types/menu.ts`).

## Прочие настройки сайта

| Что изменить | Файл |
|---|---|
| Дополнительные ингредиенты (топпинги) и их цены | `data/modifiers.ts` |
| Категории меню | `data/categories.ts` |
| Номер WhatsApp пиццерии | `config/whatsapp.ts` |
| Адрес, телефон, Instagram, часы работы, зона бронирования, координаты карты | `config/restaurant.ts` |
| Условия доставки: мин. сумма, стоимость, бесплатная доставка от, зоны, время | `config/delivery.ts` |
| Название сайта, SEO-описание, OG-изображение | `config/site.ts` |

### Номер WhatsApp

Откройте `config/whatsapp.ts` и замените значение — только цифры, без `+`, пробелов и скобок:

```ts
export const WHATSAPP_NUMBER = "79281234567";
```

### Фотографии

Меню состоит из трёх разделов — неаполитанская пицца, римская пицца и напитки:

- `public/images/menu/*.webp` — неаполитанская пицца.
- `public/images/roman/*.webp` — римская пицца.
- `public/images/drinks/*.webp` — напитки.
- `public/images/interior/*.webp` — фото интерьера и вывески пиццерии.
- `public/images/hero/pizza-hero.webp` — фон главного экрана.
- `public/images/uploads/*.webp` — фото, загруженные через админ-панель (создаётся автоматически).

Если у позиции меню нет фотографии, вместо битой ссылки автоматически показывается аккуратная минималистичная плашка с иконкой (компонент `components/menu/DishImage.tsx`). Самый простой способ добавить фото — кнопка «Загрузить фото» в форме блюда в `/admin`: выбираете файл с телефона или компьютера, он автоматически сжимается и сохраняется, путь подставляется сам. Также можно указать путь вручную, если файл уже лежит в `public/images/...`, например:

```
/images/roman/quattro-stagioni.webp
```

  booking/                 форма бронирования

## Как устроена отправка в WhatsApp

Файл `utils/whatsappMessage.ts` формирует текст сообщения (заказ или бронь) по данным формы и корзины, `config/whatsapp.ts` собирает ссылку вида `https://wa.me/НОМЕР?text=...`. При отправке формы сайт открывает эту ссылку в новой вкладке — так как без WhatsApp Business API невозможно отправить сообщение автоматически, пользователь подтверждает отправку нажатием кнопки внутри WhatsApp. Корзина при этом не очищается сразу: после открытия WhatsApp появляется отдельная кнопка «Заказ отправлен, очистить корзину». Бронирование дополнительно сохраняется на сервере (см. выше), поэтому администратор видит заявку в панели, даже если клиент не нажал «Отправить» в WhatsApp.

## Проверено перед сдачей

- `npx tsc --noEmit` и `eslint` — без ошибок.
- `npm run build` — сборка проходит, публичные страницы без завязки на пользовательские данные остаются статическими, `/`, `/menu` и админ-раздел — динамические (SSR на каждый запрос).
- Корзина: добавление, изменение количества, удаление, подсчёт суммы, сохранение в localStorage.
- Модальное окно блюда: выбор размера, доп. ингредиентов, удаление ингредиентов, пересчёт стоимости.
- Оформление заказа: валидация полей, формирование сообщения и ссылки WhatsApp.
- Бронирование: запрет прошедших дат и времени вне часов работы, сохранение заявки на сервере, формирование сообщения WhatsApp.
- Админ-панель: вход по паролю, защита `/admin/*` и `/api/admin/*` от неавторизованного доступа, добавление/редактирование/удаление блюда — с мгновенным отражением на публичном сайте, список бронирований.
- Загрузка фото: сохранение и сжатие корректного изображения, отклонение повреждённого файла и файла без выбора, защита роута от неавторизованных запросов — проверено напрямую через API и через форму в браузере.
